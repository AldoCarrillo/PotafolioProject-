# Original project sources

This folder keeps the original source submissions that the portfolio features are based on. Each project has a descriptive folder name:

```text
projects/
  budget-baller/
  code-quiz/
  fitness-tracker/
  note-taker/
  password-generator/
  readme-generator/
  team-builder/
  weather-dashboard/
  work-day-scheduler/
```

The original source and project documentation are committed to this repository. Do not add nested `.git` folders, installed dependencies such as `node_modules`, generated build output such as `dist`, or secrets and `.env` files. These original submissions are preserved for reference; the runnable portfolio versions live in `src/features/` and have individual pages.
